### Etch-A-Sketch

It's a fun and compact project featuring 'Etch A Sketch' functionality! Users can draw on a customizable grid, choose colors, and reset the board. Here are the key points about the project:

#### Features

<ul>
<li>Draw with Hover : Sketch freely by hovering over the grid.</li>
<li>Resize Board : Customize the board size for varied drawing experiences.</li>
<li>Color Choice : Select black or random colors to paint with.</li>
<li>Simple Setup : Clear instructions make setting up and using the board easy.</li>
<li>Reset Option : Start a new drawing anytime with the reset button.</li>
</ul>
